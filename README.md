## 🚀 Featured Project

### 🎓 Student Performance Prediction System

A machine learning project that predicts student final scores using factors such as study habits, attendance, and previous performance.

**Project highlights**

- 🐍 Built using Python, Pandas and scikit-learn
- 📊 Includes five visualizations for exploratory data analysis and model evaluation
- 🤖 Compares Linear Regression and Random Forest
- 📈 Reported results: MAE **7.99** | RMSE **9.86** | R² **0.52**
- 🎯 Explores how predictive analytics can help identify students who may need additional academic support

**Technologies:** `Python` `Pandas` `Scikit-learn` `Seaborn`
